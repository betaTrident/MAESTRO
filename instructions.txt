Instructions to run the program:

## Create virtual environment
- py -m venv venv

## Activate venv
- venv\scripts\Activate

## Install requirements
- pip install -r requirements.txt

## Create a /data directory in root folder
- Extract "The Truman Show - train" from .zip and store to /data
- Do the same for other datasets

## Sample run of the dataset:

```bash
python main.py --dataset The Truman Show - train
```
